# StepCounter

Шагомер на Jetpack Compose. Шаги приходят с датчика `TYPE_STEP_COUNTER`, из них считаются дистанция, калории и активные минуты с поправкой на длину шага.

На главном экране кольца прогресса по целям, ещё есть статистика по дням (график нарисован на `Canvas`, без библиотек) и достижения. История лежит в текстовом файле, одна строка на день. Если семь раз тапнуть по заголовку настроек, откроется редактор этого файла.

Расчёты и достижения покрыты тестами: `StepMathTest`, `AchievementsTest`.

minSdk 34.
